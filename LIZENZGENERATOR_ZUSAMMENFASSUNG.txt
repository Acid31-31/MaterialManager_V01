█ 🔑 WIE DER PROZESS FUNKTIONIERT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ HARDWARE-ID ERHALTEN
   Kunde öffnet MaterialManager V01
   → Menü "Hilfe" → "Lizenzinformationen"
   → Hardware-ID kopieren (z.B. "ABC123DEF456GHI789JKL012MNO345PQR")

2️⃣ LIZENZSCHLÜSSEL GENERIEREN
   Sie führen aus:
   dotnet run "ABC123DEF456GHI789JKL012MNO345PQR" "Firmennamen" 1
   
   Generator erstellt: MM-4A7F-9B2E-C5D1-8K3L

3️⃣ LIZENZSCHLÜSSEL AKTIVIEREN
   Kunde im Programm:
   → Menü "Hilfe" → "Lizenz aktivieren"
   → Lizenzschlüssel eintragen: MM-4A7F-9B2E-C5D1-8K3L
   → Firmenname eintragen: "Firmennamen"
   → Aktivieren
   
   ✓ Lizenz aktiviert!
   Gültig bis: [Datum]


█ 🔒 SICHERHEIT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Das System verwendet:

✓ HMAC-SHA256 Verschlüsselung
  - Lizenzschlüssel können nicht gefälscht werden
  - Master Secret ist in Services\LicenseKeyGenerator.cs gespeichert

✓ Hardware-gebundene Lizenzen
  - Jede Lizenz ist an die Hardware-ID des Computers gebunden
  - Computer-spezifisch (Computername, CPU, OS-Version, Benutzer)

✓ Ablaufdatum-Verifikation
  - Kryptographisch in den Schlüssel eingebettet
  - Kann nicht nachträglich geändert werden

✓ Manipulations-Erkennung
  - Lokale Lizenzdatei mit Hash-Prüfung
  - Änderungen werden erkannt


█ 📋 WICHTIGE INFORMATIONEN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MASTER SECRET
  Speicherort: Services\LicenseKeyGenerator.cs
  Wert: "MM_V01_MASTER_SECRET_2025_PRODUCTION"
  
  ⚠️ WICHTIG:
  - Ändern Sie es NICHT nach Ausstellung von Lizenzen!
  - Halten Sie es geheim
  - Ältere Lizenzen würden ungültig

LIZENZFORMATE
  Schlüssel:      MM-XXXX-XXXX-XXXX-XXXX (z.B. MM-4A7F-9B2E-C5D1-8K3L)
  Hardware-ID:    24 Base64-Zeichen (SHA256 Hash)
  Ablaufdatum:    Format: yyyyMMdd (z.B. 20260115 für 15.01.2026)

GÜLTIGKEIT
  - Demo-Modus: 30 Tage (automatisch)
  - Vollversion: Konfigurierbar (1, 2, 3,... Jahre)
  - Keine Internet-Verbindung erforderlich

FEHLER: "Hardware-ID ist ungültig"
→ Lösung: Kopieren Sie die Hardware-ID direkt vom Kunden (keine Typos/Leerzeichen)

FEHLER: "Lizenzschlüssel funktioniert nicht"
→ Lösung: Prüfen Sie, dass die gleiche Hardware-ID und der Firmenname verwendet wurden

FEHLER: "Master Secret wurde geändert"
→ Lösung: Ändern Sie es nicht! Generieren Sie neue Lizenzen mit dem aktuellen Secret

FEHLER: "Python-Skript funktioniert nicht"
→ Lösung: Installieren Sie Python 3.x (https://python.org)
