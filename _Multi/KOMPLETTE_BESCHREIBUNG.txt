║                    MATERIALMANAGER V01 - MULTI-PC BESCHREIBUNG                ║
╚════════════════════════════════════════════════════════════════════════════════╝

Ziel
====
MaterialManager V01 auf mehreren PCs nutzen, sodass alle Benutzer denselben
Materialbestand sehen und Änderungen gegenseitig sichtbar sind.

Wichtige Grundregel
===================
- Das Programm wird auf JEDEM PC installiert (oder portable gestartet).
- Gemeinsame Daten laufen über EINEN zentralen Netzwerkordner.
- Auf den Serverordner kommt NUR die Datenbasis (Excel-Datei + Lock-Datei),
  nicht die komplette EXE-Installation.


1) Architektur (einfach erklärt)
================================
Jeder PC:
- hat eigenes Programm (MaterialManager_V01.exe)
- hat eigene lokale Lizenzdatei (%LocalAppData%\MaterialManager_V01\.license)

Gemeinsamer Serverordner (z. B. \\SERVER\MaterialManagerData):
- materialbestand.xlsx
- .lock (wird automatisch verwaltet)

Vorteil:
- Alle PCs arbeiten auf derselben Datenquelle
- Neue Materialien werden synchron sichtbar


2) Was auf den Server MUSS / NICHT MUSS
=======================================
MUSS in den Serverordner:
- materialbestand.xlsx
- Schreib-/Leserechte für alle Benutzer

NICHT notwendig im Serverordner:
- MaterialManager_V01.exe
- DLLs / Runtime-Dateien
- komplette USB_Installation


3) Installation auf mehreren PCs (USB)
======================================
Für jeden Ziel-PC wiederholen:

A) USB einstecken
B) START_MaterialManager_Multi.bat öffnen
C) Option 2 "Auf diesem PC installieren (lokal)"
D) UAC/Admin bestätigen (für Program Files)
   - falls abgebrochen: Fallback nach %LocalAppData%\MaterialManager_V01
E) Programm startet

Alternative ohne Installation:
- Option 1 "Direkt von USB starten (portable)"


4) Netzwerkverbindung einrichten (pro PC)
=========================================
In der Anwendung:
- Menü: Netzwerk-Einstellungen
- Netzwerkmodus aktivieren
- denselben Pfad auf allen PCs eintragen, z. B.:
  \\SERVER\MaterialManagerData

Wichtig:
- Alle PCs müssen exakt denselben Pfad nutzen
- Benutzer brauchen Lesen + Schreiben


5) Synchronisation im Betrieb
=============================
- Dateiänderungen werden überwacht (FileWatcher)
- Automatischer Reload wird ausgelöst
- Sperrdatei (.lock) verhindert Kollisionen

Praxis-Hinweise:
- Excel-Datei nicht dauerhaft in Excel exklusiv offen lassen
- Bei Netzwerkunterbrechung kurz warten und erneut laden


6) Lizenzierung bei Multi-PC
============================
- Lizenz ist hardwaregebunden
- Jeder PC braucht seine eigene Aktivierung
- Vorgehen pro PC:
  1. Hardware-ID im Lizenzdialog kopieren
  2. Lizenzschlüssel erzeugen
  3. Aktivieren


7) Empfohlene Reihenfolge für Rollout
=====================================
1. Serverordner erstellen (\SERVER\MaterialManagerData)
2. Rechte setzen (Read/Write für alle Nutzer)
3. Ersten PC installieren und Netzwerkpfad eintragen
4. Test: Material anlegen -> Datei wird gespeichert
5. Zweiten PC installieren und denselben Pfad setzen
6. Test: Änderung auf PC1 erscheint auf PC2
7. Danach restliche PCs ausrollen


8) Checkliste für morgen (Schnelltest)
======================================
[ ] USB-Paket vorhanden
[ ] START_MaterialManager_Multi.bat startet
[ ] Installation auf PC1 erfolgreich
[ ] Installation auf PC2 erfolgreich
[ ] Beide PCs auf denselben Netzwerkpfad konfiguriert
[ ] materialbestand.xlsx liegt im Serverordner
[ ] Neue Eingabe auf PC1 auf PC2 sichtbar
[ ] Lizenz auf jedem PC aktiviert


9) Häufige Fehler und Lösungen
==============================
Fehler: Zugriff verweigert bei Installation
- Lösung: UAC bestätigen oder Benutzerordner-Fallback nutzen

Fehler: PCs sehen keine gemeinsamen Daten
- Lösung: gleicher Netzwerkpfad auf allen PCs prüfen

Fehler: Datei blockiert
- Lösung: Excel schließen, erneut speichern/laden

Fehler: weiter Demo statt Vollversion
- Lösung: Lizenzaktivierung pro PC prüfen (hardwaregebunden)


10) Ergebnis
============
Ja, Multi-PC-Betrieb ist möglich und vorgesehen:
- Programm pro PC installiert
- gemeinsame Daten im Netzwerkordner
- automatische Synchronisation zwischen PCs

Ende.
