█ SUPER SCHNELL (2 SCHRITTE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SCHRITT 1: Hardware-ID vom Kunden erhalten
  ◉ Im MaterialManager: Menü → Hilfe → Lizenzinformationen
  ◉ Hardware-ID kopieren (z.B. "ABC123...")

SCHRITT 2: Lizenzschlüssel generieren
  ◉ PowerShell/CMD: cd Tools
  ◉ Eingeben: dotnet run "ABC123..." "Firmenname" 1
  ◉ Lizenzschlüssel kopieren: MM-XXXX-XXXX-XXXX-XXXX
  ◉ An Kunde versenden


█ KOMMANDOZEILE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# Standard (1 Jahr gültig)
dotnet run "HardwareID" "Firmenname"

# Mit Laufzeit (z.B. 3 Jahre)
dotnet run "HardwareID" "Firmenname" 3

# Beispiel
dotnet run "ABC123DEF456GHI789JKL012" "Musterfirma GmbH" 1

█ AKTIVIERUNG (IM PROGRAMM)

█ FEHLERBEHEBUNG
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "dotnet: command not found"
→ .NET 8.0 SDK installieren (https://dot.net/download)

❌ "Python not found"
→ Python 3 installieren (https://python.org)

❌ "Hardware-ID ungültig"
→ Vom Kunden direkt kopieren, keine Typos

❌ "Lizenzschlüssel funktioniert nicht"
→ Gleiche Hardware-ID und Firmenname verwenden
