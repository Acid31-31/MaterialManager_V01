3 OPTIONEN ZUM INSTALLIEREN:
================================================================================

OPTION 1: INTERAKTIV (EMPFOHLEN)
───────────────────────────────
1. Doppelklick: Install_MultiPC.bat
2. Menü wählen
3. Anweisungen folgen
4. Fertig!

OPTION 2: DIREKT VON HIER
────────────────────────
1. MaterialManager\MaterialManager_V01.exe starten
2. Installation läuft ab
3. Fertig!

OPTION 3: VON USB-STICK (MEHRERE PCs)
──────────────────────────────────────
1. USB_Installation Ordner auf USB kopieren
2. USB einstecken auf Ziel-PC
3. START_MaterialManager.bat doppelklicken
4. Auf jedem PC wiederholen!


================================================================================
USB-PAKET VORBEREITEN (einmalig)
================================================================================

1. USB-Stick min. 250 MB bereitstellen

2. USB_Installation Ordner VOLLSTÄNDIG kopieren:
   Quelle: USB_Installation\
   Ziel:   E:\ (Ihr USB-Laufwerk)

3. Auf USB sollte dann so aussehen:
   USB_Installation\
   ├── MaterialManager\
   │   ├── MaterialManager_V01.exe
   │   └── [weitere Dateien]
   ├── START_MaterialManager.bat
   └── README.txt

4. Fertig! USB ist jetzt einsatzbereit für beliebig viele PCs!


================================================================================
AUF EINEM ZIEL-PC INSTALLIEREN
================================================================================

Von USB:
  1. USB einstecken
  2. Doppelklick: START_MaterialManager.bat
  3. Installation läuft automatisch
  4. Lizenzschlüssel eingeben
  5. Fertig!

Dauer: ca. 5 Minuten pro PC
