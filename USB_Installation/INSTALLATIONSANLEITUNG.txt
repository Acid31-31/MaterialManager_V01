================================================================================
SCHRITT 1: USB VORBEREITEN (Einmalig)
================================================================================

1. USB-Stick (mind. 250 MB) bereitstellen
2. Ordner öffnen: USB_Installation
3. GESAMTEN Ordner "USB_Installation" kopieren
4. AUF USB einfügen

USB sieht dann so aus:
   E:\USB_Installation\
   ├── MaterialManager\
   │   └── MaterialManager_V01.exe
   ├── START_MaterialManager.bat
   └── [weitere Dateien]

================================================================================
SCHRITT 2: AUF JEDEM PC INSTALLIEREN
================================================================================

OPTION A - VON USB STARTEN (Schnell, kein Installation)
─────────────────────────────────────────────────────
1. USB einstecken
2. Ordner öffnen: USB_Installation
3. Doppelklick: START_MaterialManager.bat
4. App startet sofort!
5. Fertig! ✅

Dauer: 2 Sekunden


OPTION B - FEST AUF PC INSTALLIEREN (Mit Desktop-Verknüpfung)
─────────────────────────────────────────────────────────
1. USB einstecken
2. Ordner öffnen: USB_Installation
3. Doppelklick: Install_LocalPC.bat
4. Rechtsklick → "Als Administrator ausführen"
5. Installation läuft automatisch
6. App wird installiert zu: C:\Program Files\MaterialManager
7. Desktop-Verknüpfung wird erstellt
8. Fertig! ✅

Dauer: ca. 1-2 Minuten


================================================================================
WICHTIG - UNTERSCHIED:
================================================================================

START_MaterialManager.bat
→ App startet direkt von USB
→ Schnell, einfach
→ Kein Installation nötig
→ Für Test oder Einzelplatz

Install_LocalPC.bat
→ App wird fest auf C:\ installiert
→ Desktop-Verknüpfung
→ Für mehrere Mitarbeiter
→ Empfohlen für Büros

================================================================================
HÄUFIGE FRAGEN:
================================================================================

F: Wo ist die EXE?
A: USB_Installation\MaterialManager\MaterialManager_V01.exe

F: Installation funktioniert nicht?
A: Adminrechte erforderlich! Rechtsklick → "Als Administrator"

F: Kann ich die App von USB und installiert haben?
A: JA! Beides funktioniert gleichzeitig. Wähle eine Option!

F: Wie viel Speicher braucht die App?
A: ~150 MB installiert. USB braucht ~250 MB.

F: Kann ich mehrere PCs mit 1 USB machen?
A: JA! USB beliebig oft wiederverwendbar!


================================================================================
SUPPORT:
================================================================================

Problem → Lösung:

"Admin-Fehler"
→ Rechtsklick auf BAT → "Als Administrator ausführen"

"Datei nicht gefunden"
→ Prüfe: USB_Installation\MaterialManager\MaterialManager_V01.exe existiert?

"Installation friert ein"
→ Warten (Antivirus prüft) oder neu starten

"App startet nicht nach Installation"
→ Manuell starten: C:\Program Files\MaterialManager\MaterialManager_V01.exe
