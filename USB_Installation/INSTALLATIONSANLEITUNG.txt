================================================================================
                  MATERIALMANAGER V01 - INSTALLATIONSANLEITUNG
================================================================================

DATUM: 09.04.2026
VERSION: 1.2.1
STATUS: AKTUELL

================================================================================
1) USB VORBEREITEN (EINMALIG)
================================================================================

1. Ordner `USB_Installation` vollständig auf USB-Stick kopieren.
2. Prüfen, dass `MaterialManager\MaterialManager_V01.exe` vorhanden ist.


================================================================================
2) INSTALLATION / START AUF JEDEM PC
================================================================================

OPTION A - DIREKTSTART (ohne feste Installation)
-------------------------------------------------
1. USB einstecken
2. `START_MaterialManager.bat` doppelklicken
3. App startet direkt

OPTION B - FESTE INSTALLATION (empfohlen)
-----------------------------------------
1. USB einstecken
2. `Install_LocalPC.bat` als Administrator ausführen
3. Installation nach `C:\Program Files\MaterialManager`
4. Desktop-Verknüpfung wird erstellt

OPTION C - GUI-INSTALLER
------------------------
1. `INSTALL.bat` ausführen
2. Anweisungen im Installer folgen


================================================================================
3) NETZWERKBETRIEB FÜR MEHRERE PCs
================================================================================

In der App: `Einstellungen -> Netzwerk`

- Netzwerkmodus aktivieren
- Gemeinsamen Datenordner wählen
- Optional separaten Archivordner wählen

Empfohlen:

- Daten: `\\SERVER\MaterialManager\Daten`
- Archiv: `\\SERVER\MaterialManager\Archiv`


================================================================================
4) SPEICHERORTE (WICHTIG)
================================================================================

Materialdaten für alle PCs (bei Netzwerkmodus):
- `\\SERVER\MaterialManager\Daten\materialbestand.xlsx`

Automatische Tages-Backups der Materialdatei:
- `\\SERVER\MaterialManager\Daten\Backups\YYYY-MM-DD\...`

Archiv alter Aufträge:
- Primär: eingestellter Archivpfad
- Sonst: `<Netzwerkpfad>\Auftragsarchiv`
- Struktur: `<Basis>\Jahr\KW_xx\Auftragsnummer\` mit `auftrag.json` + `PDF\`

Lokal (ohne Netzwerkmodus):
- `%LOCALAPPDATA%\MaterialManager_V01\Data\materialbestand.xlsx`
- `%LOCALAPPDATA%\MaterialManager_V01\Auftragsarchiv`


================================================================================
5) SYSTEMANFORDERUNGEN
================================================================================

- Windows 10/11 (64-Bit)
- ausreichend Speicherplatz
- Administrator-Rechte für feste Installation
- .NET 8 ist im Paket enthalten


================================================================================
6) KURZ-CHECK NACH INSTALLATION
================================================================================

[ ] App startet fehlerfrei
[ ] Lizenz aktiviert
[ ] Netzwerkpfade erreichbar
[ ] Materialdatei wird im Zielordner aktualisiert
