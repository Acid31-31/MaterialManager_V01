MATERIALMANAGER V01 - KOMPLETTE INSTALLATIONSANLEITUNG (MEHRERE PCS)
================================================================================

Datum dieser Anleitung: 09.04.2026
Version: 1.2.1
Status: AKTUELL

================================================================================
1) ZIEL DIESER ANLEITUNG
================================================================================

Diese Anleitung beschreibt:

- Installation auf mehreren PCs mit dem Ordner `USB_Installation`
- empfohlene Netzwerkkonfiguration
- zentralen Speicherort für Materialdaten für alle PCs
- Speicherort für Archive abgeschlossener Aufträge
- Zertifikats-Setup für signierte Updates


================================================================================
2) USB-STRUKTUR (AKTUELLER STAND)
================================================================================

Im Ordner `USB_Installation` sind die wichtigsten Dateien:

- `MaterialManager\MaterialManager_V01.exe` (Hauptprogramm)
- `START_MaterialManager.bat` (Start direkt aus USB-Ordner)
- `Install_LocalPC.bat` (lokale feste Installation auf dem PC)
- `INSTALL.bat` (Start des aktuellen GUI-Installers)
- `INSTALL_GUI.ps1` (grafischer Installer)
- `INSTALL_CERTIFICATE.bat` (Zertifikat einmalig auf Ziel-PC installieren)
- `MaterialManager_CodeSigning_PUBLIC.cer` (öffentliches Zertifikat)


================================================================================
3) WICHTIG: ZERTIFIKAT PRO ZIEL-PC EINMALIG INSTALLIEREN
================================================================================

Vor dem eigentlichen Update/Installationslauf:

1. `INSTALL_CERTIFICATE.bat` als Administrator ausführen.
2. Danach Installation/Update wie gewohnt starten.

Hinweis:

- Die `.pfx` bleibt nur auf dem Build-PC.
- Für Ziel-PCs wird nur das öffentliche `.cer` verwendet.


================================================================================
4) INSTALLATION AUF MEHREREN PCS
================================================================================

Variante A: Schnellstart ohne feste Installation
-----------------------------------------------

1. `USB_Installation` auf den USB-Stick kopieren.
2. Auf Ziel-PC USB einstecken.
3. `START_MaterialManager.bat` ausführen.
4. App startet direkt.

Geeignet für: schnelle Inbetriebnahme / Test.


Variante B: Feste Installation pro PC (empfohlen)
-------------------------------------------------

1. USB einstecken.
2. `Install_LocalPC.bat` per Rechtsklick als Administrator ausführen.
3. Programm wird nach `C:\Program Files\MaterialManager` kopiert.
4. Desktop-Verknüpfung wird angelegt.

Geeignet für: produktive Arbeitsplätze.


Variante C: GUI-Installer
-------------------------

1. `INSTALL.bat` starten.
2. Der aktuelle GUI-Installer (`INSTALL_GUI.ps1`) führt durch den Ablauf.


================================================================================
5) NETZWERKEINSTELLUNGEN (MEHRERE PCS)
================================================================================

In der App unter `Einstellungen -> Netzwerk`:

1. Netzwerkmodus aktivieren.
2. Einen gemeinsamen Netzwerkordner für Materialdaten setzen.
3. Optional einen separaten Archivordner setzen.

Empfehlung (Beispiel):

- Materialdaten-Basis: `\\SERVER\MaterialManager\Daten`
- Auftragsarchiv-Basis: `\\SERVER\MaterialManager\Archiv`

Wichtig:

- Alle PCs müssen Lese-/Schreibrechte auf diese Freigaben haben.
- Der Pfad muss als Ordner angegeben werden, nicht als einzelne Datei.


================================================================================
6) WO WERDEN DIE MATERIALDATEN FÜR ALLE PCS GESPEICHERT?
================================================================================

Wenn Netzwerkmodus aktiv ist:

- Datei: `materialbestand.xlsx`
- Speicherort: im eingestellten Netzwerkordner
- Beispiel: `\\SERVER\MaterialManager\Daten\materialbestand.xlsx`

Zusätzlich erstellt die App tägliche Sicherungen:

- `\\SERVER\MaterialManager\Daten\Backups\YYYY-MM-DD\materialbestand_HHMMSS.xlsx`
- Aufbewahrung: 30 Tage

Wenn Netzwerkmodus NICHT aktiv ist:

- Lokal pro PC unter:
  `%LOCALAPPDATA%\MaterialManager_V01\Data\materialbestand.xlsx`


================================================================================
7) WO WERDEN ARCHIVE ALTER AUFTRÄGE GESPEICHERT?
================================================================================

Archiv-Basis wird so aufgelöst:

1. Wenn in den Netzwerkeinstellungen ein Archivpfad gesetzt ist -> dieser Pfad.
2. Sonst (bei aktivem Netzwerkmodus) -> `<Netzwerkpfad>\Auftragsarchiv`.
3. Sonst lokal -> `%LOCALAPPDATA%\MaterialManager_V01\Auftragsarchiv`.

Struktur im Archiv:

`<Archiv-Basis>\<Jahr>\KW_<Kalenderwoche>\<Auftragsnummer>\`

Darin:

- `auftrag.json` (Auftrags- und Materialdaten)
- Ordner `PDF\` mit kopierten PDF-Dateien

Beispiel:

`\\SERVER\MaterialManager\Archiv\2026\KW_15\A-12345\auftrag.json`


================================================================================
8) AUTOMATISCHE ARCHIV-REGELN
================================================================================

- Bei Abschluss eines Auftrags werden Daten + PDFs archiviert.
- Alte KW-Archivdaten werden automatisch nach 12 Monaten bereinigt.


================================================================================
9) EMPFOHLENE FREIGABE-STRUKTUR IM NETZWERK
================================================================================

Auf Dateiserver (Beispiel):

`\\SERVER\MaterialManager\`
- `Daten\`           (enthält `materialbestand.xlsx` + `Backups`)
- `Archiv\`          (enthält Jahres-/KW-Archiv)

Freigabe-Rechte:

- Anwendergruppe MaterialManager: Lesen + Ändern
- IT/Admin: Vollzugriff

================================================================================
11) FEHLERBILDER
================================================================================

Problem: Netzwerkpfad nicht erreichbar
Lösung: Freigabe, Rechte und UNC-Pfad prüfen.

Problem: Archiv kann nicht erstellt werden
Lösung: Archivpfad setzen oder Schreibrechte auf Freigabe prüfen.

Problem: Unterschiedliche Datenstände auf PCs
Lösung: Sicherstellen, dass auf allen PCs derselbe Netzwerkpfad konfiguriert ist.
