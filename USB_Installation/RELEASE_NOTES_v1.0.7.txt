📋 INSTALLATION & VERWENDUNG
================================================================================

INSTALLATION:
1. Rechtsklick auf INSTALL.bat → "Als Administrator ausführen"
2. Installer folgen (5 Schritte)
3. Lizenzvereinbarung akzeptieren
4. Installationspfad wählen (Standard: C:\Program Files\MaterialManager_V01)
5. Installation abschließen
6. Optional: App sofort starten

NACH INSTALLATION:
- Desktop-Verknüpfung verfügbar
- Programm über Systemsteuerung → Programme & Features deinstallierbar
- KEINE Admin-Rechte mehr nötig zum Starten!

DEINSTALLATION:
- Systemsteuerung → Programme & Features → MaterialManager V01 → Deinstallieren
- ODER: C:\Program Files\MaterialManager_V01\UNINSTALL.bat
