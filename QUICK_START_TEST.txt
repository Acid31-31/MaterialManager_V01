█ 📞 SUPPORT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Lizenzschlüssel wird nicht akzeptiert

Lösung 1 - Hardware-ID prüfen:
  1. MaterialManager → Hilfe → Lizenzinformationen
  2. Hardware-ID kopieren
  3. Mit TEST_LICENSE_BUGFIX_V2.bat Output vergleichen
  4. Müssen EXAKT gleich sein!

Lösung 2 - Alte Lizenz löschen:
  1. Explorer öffnen
  2. In Adressleiste: %APPDATA%
  3. Ordner MaterialManager_V01 → .license Datei
  4. Löschen
  5. Test erneut versuchen

Lösung 3 - Debug Output prüfen:
  1. Visual Studio öffnen
  2. Debug → Windows → Output
  3. Nach [License] Meldungen suchen
  4. Zeigt exakte Problemursache
