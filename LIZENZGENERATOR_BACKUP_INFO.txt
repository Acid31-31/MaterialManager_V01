█ VERWENDUNGSSZENARIEN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. EINZELNE LIZENZAUSGABE
   dotnet run "HardwareID" "Firmenname" 1
   → Für Einzelkunden, manuelle Verarbeitung

2. BATCH-VERARBEITUNG
   CSV importieren → for-Schleife mit dotnet run
   → Für Massenlizenzen

3. E-COMMERCE INTEGRATION
   Website → API-Call → Lizenzgenerator → Email
   → Automatische Lizenzversendung

4. KUNDENMANAGEMENT
   python license_manager.py
   → Verwaltung aller ausgegebenen Lizenzen
   → CSV-Export für Excel/Reports

5. SUPPORT & RENEWALS
   Kunde: Hardware-ID anfragen
   Admin: dotnet run mit gleicher ID + neuer Laufzeit
   → Schnelle Verlängerungen

- Master Secret NICHT ändern

PROBLEMFÄLLE:
- Kunden-Hardware ändert sich → Neue Lizenz nötig

- Systemabsturz → Lizenzdatei bleibt intakt
